# Changelog

## 1.0.0 (2026-11-19)

First release of Hookline, an original Sunrise native mod by Zekrenlight (MIT).

- AFK fishing that reels on your own bobber's splash, recasts with pace variance, and keeps or tosses each catch (with per-enchant rules for books, rods and bows).
- Optional deposit of kept catch into a chest you open, meals from the off-hand or hotbar, idle rest, look-around, worn-rod handling and leaving below three hearts.
- A tabbed panel (Loot, Enchants, Behavior, Stats) on **O** or `/hookline panel`; Keep and Toss stay green and red.
- Built for Minecraft Java 26.3, Sunrise API 0.2, Mod SDK `9425651` (`94256510f74e6843754e0a93fd9e4da7e45b1056`), mixins `e59da909`.
- Settings open in the shared Sunrise dark card (`#0F1118`, accent edge, charcoal chips) from SunnyMods' Settings button, Sunrise's Mods list, or the mod's settings key; its hooks act only on the mod's own Options page, so it works alone or with the other Sunrise mods.
- An **Accent colour** setting (Sunrise orange `#F9801D` at first) with eight presets and Reset.
